# Validation by model group

This page compares RSYC predictions with plot observations for every
combination of response, model scale, and spatial level (model release
**v20260923**). Each point is one age class of one curve: the weighted
mean of the plot observations (x axis) against the mean RSYC prediction
for the same plots (y axis). Panels show the generic model, the
coniferous and broadleaf models, and the species models. Species are
ordered by number of points.

Below each scatterplot, boxplots show the prediction error (RSYC − plot)
by age class. AGB points with plot means of 400 Mg/ha or more are
excluded, and panels with fewer than three points are omitted. See
[Model
validation](https://ptompalski.github.io/RSYC/articles/validation.md)
for the method and the [Validation
explorer](https://ptompalski.github.io/RSYC/articles/validation-explorer.md)
for individual curves.
