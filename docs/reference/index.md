# Package index

## Predict yield and build datasets

Estimate yield curves and combine predictions with spatial data.

- [`predict_rsyc()`](https://ptompalski.github.io/RSYC/reference/predict_rsyc.md)
  : Estimate Biomass or Volume from an RSYC Yield Curve
- [`build_rsyc_dataset()`](https://ptompalski.github.io/RSYC/reference/build_rsyc_dataset.md)
  : Build an RSYC Spatial Yield-Curve Dataset

## Discover available models

Find published curves, species, and geographic strata.

- [`available_rsyc_models()`](https://ptompalski.github.io/RSYC/reference/available_rsyc_models.md)
  : List Published RSYC Models
- [`rsyc_species()`](https://ptompalski.github.io/RSYC/reference/rsyc_species.md)
  : List Species Available in RSYC Models
- [`rsyc_strata()`](https://ptompalski.github.io/RSYC/reference/rsyc_strata.md)
  : List Areas Available in RSYC Models
- [`species_codes()`](https://ptompalski.github.io/RSYC/reference/species_codes.md)
  : List Available Species Codes and Names

## Access spatial boundaries

Download and read the polygons associated with RSYC models.

- [`rsyc_boundaries()`](https://ptompalski.github.io/RSYC/reference/rsyc_boundaries.md)
  : Read RSYC Boundary Maps
- [`download_rsyc_boundaries()`](https://ptompalski.github.io/RSYC/reference/download_rsyc_boundaries.md)
  : Download RSYC Ecological Boundaries

## Package datasets

Model metadata and the bundled tile grid.

- [`RSYC_models`](https://ptompalski.github.io/RSYC/reference/RSYC_models.md)
  : Published RSYC Yield-Curve Data
- [`RSYC_tiles`](https://ptompalski.github.io/RSYC/reference/RSYC_tiles.md)
  : RSYC Tile Grid (150 x 150 km)
